# You are God
An experiential music game, coded in Processing, Python, and MaxMSP.

## Video Demo
[![video here](https://img.youtube.com/vi/26L39MthBUY/maxresdefault.jpg)](https://youtu.be/26L39MthBUY)


## Notes
This game uses [MaxPy](https://github.com/Barnard-PL-Labs/MaxPy) and a Python server to communicate between Processing and MaxMSP.
