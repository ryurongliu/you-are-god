# You are God
An experiential music game exploring time, choice, and creation. Coded in MaxMSP, Processing, Python, and Arduino.

## Video Demo
[![video here](https://img.youtube.com/vi/26L39MthBUY/maxresdefault.jpg)](https://youtu.be/26L39MthBUY)


## Notes
This game uses the open-source Python package [MaxPy](https://github.com/Barnard-PL-Labs/MaxPy) to live-generate maxpatches. It also uses a Python server to communicate between Processing and MaxMSP. The game was demoed at New Interfaces for Musical Expression conference in June 2023 as a demonstration of MaxPy.
